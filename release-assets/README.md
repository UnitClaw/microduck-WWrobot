# WWNT Robotics · Microduck Console R17 V167

**English** · [简体中文](#简体中文)

WWNT Robotics (万物拟态) branded release of the Microduck R17 V167 hardware console — rebranded, bilingual (中文 / English), defaulting to English.

- `WWNT-Microduck-Console-R17-V167.zip` — the complete console package (Python backend + web console + bundled firmware `1fa8438-feetech-ft6-control.43`).
- `WWNT-Microduck-Console-R17-V167.sha256` — SHA-256 checksum of the zip.

Extract and run `start.cmd` (Windows) / `bash start.command` (macOS/Linux) / `python console.py --dashboard --feetech --open`.
